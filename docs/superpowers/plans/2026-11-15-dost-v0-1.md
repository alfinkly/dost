# dost v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Rust terminal player for Ansible: menu, live scenes, plain-language summaries, known-error hints, chain progress.

**Architecture:** One binary. A project (`.dost/` next to the user's playbooks) is loaded into `Project`. `dost` spawns `ansible-playbook` with a bundled callback plugin that streams JSON lines; the stream feeds a `RunState`; scenes (built from level-1 widgets) render that state with `ratatui`. Nothing runs on servers except through the spawned Ansible.

**Tech Stack:** Rust stable, `ratatui`, `crossterm`, `tokio` (process, io), `clap`, `serde` + `serde_yaml_ng` + `serde_json`, `minijinja`, `regex`, `sha2`, `anyhow`, `thiserror`, `nix`, `tempfile`.

**Spec:** `docs/design.md` (Russian). The section "Уточнения после проверки строителем" overrides earlier text where they differ.

## Global Constraints

- Language Rust; TUI crates `ratatui` + `crossterm`, async with `tokio`. License Apache-2.0.
- Platforms: macOS and Linux. ansible-core 2.15+. Terminal minimum 80×24; truecolor if available, else 256/16 colours.
- No server components, no agents; runs only locally on top of `ansible-playbook`.
- Event contract v1: `ansible.builtin.debug` with `msg: { dost: { v: 1, kind, ... } }`; kinds `ports`, `link`, `node`, `step`, `note`; unknown kinds or versions are ignored without error.
- Bundled callback `dost_stream` (no `ansible.posix` dependency); enabled via `ANSIBLE_CALLBACK_PLUGINS` and `ANSIBLE_STDOUT_CALLBACK`.
- The `become` password never appears in argv, environment, a file on disk, history, logs or saved output; primary path is `--become-password-file /dev/fd/N`.
- `--check --diff` always runs first; apply only after confirmation; `danger: medium|high` needs the typed `id`; `check: false` skips the check with a visible warning.
- Events from a check run are drawn dimmed with the label "ПРОВЕРКА, предварительно".
- Events are keyed by (host, kind, key); same key overwrites, different keys accumulate.
- Chain step wording is "мог устареть", never "устарел". Without a tty: no TUI, plain step log plus summary.
- No circleburo names anywhere in the repo or demo data.

## Review Focus

1. Ansible missing or too old: `dost doctor` and `dost run` fail with a clear message, not a panic.
2. Playbook fails before any event (syntax error, unreachable host): player shows the error and matching hints, terminal restored.
3. Ctrl-C or `q` mid-run: child Ansible is terminated, terminal leaves raw mode, no password pipe left open.
4. Password containing spaces, quotes, `$`, unicode or a trailing newline is passed intact and never echoed.
5. Narrow terminal (below 80×24) and 50+ hosts: scenes degrade to a list, no panic or overflow.
6. Malformed or oversized JSON lines, and `dost` keys with wrong types, are skipped without killing the run.
7. Catalog errors (missing playbook file, unknown `after` id, bad `bind` path) are reported by `dost doctor` with file and field.
